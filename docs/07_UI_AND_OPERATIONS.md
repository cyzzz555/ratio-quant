# 产品界面、部署和运维

## 使用方式
优先建设响应式React Web/PWA。Mac浏览器/桌面Web应用全面研究，iPhone通过同一受保护的HTTPS域名访问并批准具体交易；Mac关闭不会停止云端实时行情和风控。开发期间`http://localhost:3000`仅示例，实际端口由Codex选定记录。

## 页面
- **Dashboard**：当前账户模式（STANDARD/MICRO）、权益/资金流、当日亏损、初始本金累计亏损、高水位回撤、风险锁、信号、待审批列表、系统Ready状态（含时间戳）。
- **Trade Desk**：K线(1m/5m/15m/1h/1d)、MA/EMA/MACD、价格结构、策略标记、当前及历史订单/成交、资金费/保证金/清算距离。
- **Research**：三策略独立得分、历史回测净收益、walk-forward、参数候选版本、样本外比较、历史回放（按时间水位线）。
- **Risk Center**：单笔、总计划风险、两类杠杆、Margin usage、每日/本金/高水位分开显示；风险锁详情；人工紧急停止及受控恢复。
- **System**：合约可用性、数据质量、行情延迟、同步/对账状态、警报、研究任务、审计、备份状态。

## 通知
常规：简讯；高质量：附订单参数及风险摘要，但必须进授权Web页且经2FA审批；紧急：行情失效/熔断/未知订单状态优先。通知丢失不能成为失去交易所保护性订单的单点故障。

## 运行监测
基础资源(CPU/内存/磁盘)、行情lag和闭合bar缺口、WS重连、任务时延、信号吞吐/质量、订单state ages、持仓与交易所对账差异、风险服务心跳、数据同步、独立告警发送结果。`liveness`与`trading_ready`分别显示。

## 部署
阶段0—1 Mac Docker Compose + 本地Python/Node工具链；阶段2—3上云进行长时间paper监控；阶段4安全审查后做真实API只读对账；阶段5仅获明确授权才接受真实订单。云服务器与备份成本需相对500—1000元实验资本控制，先无云或便宜单机。没有必要初期微服务/Kubernetes。
