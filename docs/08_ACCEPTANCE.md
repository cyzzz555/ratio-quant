# 验收测试计划（Codex必须自动化）

## P0只读能力检查
- Given目标合约未公开显示 When查询接口 Then标`UNKNOWN/UNAVAILABLE`且保留HTTP和时间；不能认定用户权限。
- Given仅已取得公开合约信息 When获取符号 Then`VERIFIED_PUBLIC`≠`VERIFIED_ACCOUNT`。
- Given不适用的COIN-M/Spot/股票API When尝试用作USDⓈ-M Then拒绝跨产品隐式复用。
- Given无网络/429/5xx When读接口超时 Then指数退避/限速，生成故障记录，不伪造价格。

## 行情/回测
1. 相同WS行情重复3次，产出一个bar和一个候选。
2. 5m K线未收盘，收盘确认策略不发正式信号；到位后只确认一次。
3. 只读实时流缺口，REST补全后带质量状态；严重缺口不准产生执行信号。
4. UTC+Asia/Shanghai与美国DST切换测试，日线日界与价格模式按合约实现。
5. 财报14:30标称公布，但实际供应商14:32可用 => 14:31回测看不到。
6. 新上市合约无长期历史 => 不能称策略经过长周期验证。
7. 有费用、资金费、价差、部分成交的回测可复现，并输出代码/数据/参数hash。

## 风险数学
8. `standard` 普通0.5%、优质1%，日内1.5%预警、2%锁定、10%高水位回撤锁定；跨品种相关性不设额外硬上限。
9. `micro`仅模拟候选风险配置，1%/2%、3%/5%、总5%、20/30/40/50%本金线和25/35%高水位线按优先级触发；不误当确认实盘配置。
10. 起始1000元，entry=100, stop=98，单笔1%=10元 => 数量5（无费），20x理论保证金25元；名义仓位500元不是10000元。
11. 25x需例外标记/人工批准；26x拒绝；交易所上限20x时不得把25x原批准悄悄改成20x下单。
12. 账号权益1000、名义仓位2500 => 有效杠杆2.5x，**仅在模拟开启候选2x阈值时**拒单。
13. 止损位在预估强平之后或强平信息不可确认 => 阻断新开仓；不得假设止损必定成交。
14. minQty/step/tick不满足时拒绝，不能向上凑单越过损失预算。
15. 初始1000，后额外入金100，权益650 => flow_adjusted=550 => 本金损失45%，不误算为35%。
16. P0=1000，涨到1300后回1000 => 初始本金损失0%，最高净值回撤23.0769%。
17. 程序重启、外部注资、日界切换后已持久锁不自动恢复。
18. 待确认开仓订单预占风险；模拟部分成交只释放相应预占额度，不双计/漏计。
19. 多头/空头risk和强平价方向判别正确，交易成本/风险过高拒单。

## 审批/订单/故障
20. Mac与iPhone同一approval并发点击，仅一个订单ID，最多一次真实请求。
21. 提交后连接断开但交易所订单实际存在 => 查询旧client order id对账，不发第二笔。
22. 价格、止损、杠杆、数量或spec_version改变 => 原审批hash失效、必须重审。
23. `LIVE_TRADING_ENABLED=false`时，即便所有模拟检查通过也不得访问真实交易下单方法。
24. 交易所保护单提交失败，系统进入不能继续增加风险的状态并报警。
25. 新增交易权限丢失/风控服务故障/数据延迟超线 => NO_NEW_RISK；经过预先批准且接口可用的reduce-only可以继续。
26. 实盘资格未知、账户限制未知、杠杆档位未知 => 拒绝任何模拟以外的开仓。
27. 未批准的每周研究新版本不能生效；旧版本可复查、候选版本可回滚。
28. 故障恢复前需全量核对open orders、fills、positions、balances、funding ledger，并经人工开启。
29. 任一私钥不得出现在浏览器网络、git提交、日志或导出文件。

## 验收原则
P0不需要账户凭证也能生成只读能力报告，P1数据和纯风控离线测试通过，P2实时安全降级，P3模拟盘订单全链路，P4认证/风控灾备验证，P5**明确用户授权后**小额实盘，P6图表/研究/运维。各阶段`README`记录运行命令、测试覆盖与仍未知问题。通过工程测试不意味着证明策略盈利。
