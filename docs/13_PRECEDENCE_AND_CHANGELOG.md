# 版本变更/冲突解决与资料追溯

## 用户需求权威性
42轮用户确认决策（V1.0） + 用户后续确认微资金初始本金/50%容忍（V1.1） + 用户后续确认单仓杠杆常规10—20x/最高25x（V1.2），为本包唯一明确设计意图；Codex不得把模型在解释过程中提出的补充提案写成用户同意。

## 已解决的跨版本冲突
| 原方案/矛盾 | 最终适用方式 | 状态 |
|---|---|---|
| V1.0标准账户0.5—1%、日内1.5/2%、高水位10% | 标准账户继续生效，微资金实验使用不同profile | 已确认 |
| V1.1曾建议单仓最高3x | V1.2用户明确改为常规10—20x/最高25x，3x作废 | 已确认 |
| V1.1提议账户有效杠杆2x | 单仓交易所杠杆与整个账户名义敞口不同，2x依旧只是提案 | 待批准 |
| V1.1提议本金损失40%提前停机 | 是为50%损失容忍留余量的风控建议，不是用户确认新的最大亏损线 | 待批准 |
| 42轮曾约定交易美股及商品期货 | Binance落地应对接具体可用永续衍生品，需逐合约核查，不能假装拥有股票/传统期货 | 平台已确认，能力待验证 |
| 2R分批止盈50% | 只是一笔演示样例，未冻结为策略参数 | 研究中 |
| 0—100评分 | 不能直接当预测胜率，权重和准入阈值需回测与样本外验证 | 研究中 |
| 初始本金50%最大可承受损失 | 用户容忍预算，不保证实际最大可能亏损被限制于此 | 已确认容忍，不是担保 |

## 有意延后的功能
策略自主发布、全自动无人审批开新仓、毫秒高频、分布式高可用集群、原生iOS/Mac分开开发、机器学习评分均不是V1必要条件。主线优先产品能力核验、可信数据、可回测策略、稳健纸面交易闭环。
