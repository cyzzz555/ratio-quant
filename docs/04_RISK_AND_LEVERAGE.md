# 风控统一定义：Standard 与 Micro Capital

## 配置优先级
- 用户已确认`standard`模式的历史规则：单笔0.5—1%，单日预警1.5%、熔断2%，最高净值回撤10%，同时计划风险5%，无独立相关性硬限制。
- 用户已确认`micro_capital`启动本金人民币500—1000元、可承受**初始本金最多亏损50%**、交易所单仓常规杠杆10—20x、最高25x。此处50%是个人风险容忍度，**不能作为算法保证**。
- 其余Micro数值**候选，仅研究/模拟**，包括1%/2%单笔、3%/5%单日、5%总风险、20%/30%/40%本金预警、25%/35%高水位线、2x整体有效杠杆等。见`config/settings.example.yaml`状态标签。Codex不得“默认当用户批准实盘”。

## 推荐Micro模拟候选参数（明确不是已批准实盘）
| 指标 | 提案 | 原因/动作 |
|---|---|---|
|单笔普通/优质计划风险|1% / ≤2%权益|成本/止损后计算|
|单日预警/锁新仓|3% / 5%权益|按独立可审计的风控日定义|
|组合计划风险上限|5%权益|包含未成交待执行新增风险|
|本金损失20%|预警|策略复查|
|本金损失30%|把**新增**风险预算乘0.5|不被盈利后一键重置|
|本金损失40%|停止新增风险并复核|为50%容忍度保留余地|
|本金损失50%|最终预算越线告警/禁止新增风险|并非资金强制止损保证|
|最高净值回撤25%/35%|预警/锁新仓|和本金损失指标**分别**统计|
|整体有效杠杆|2.0x提案|跨多空、跨标的名义仓位绝对值合计/权益|
|保证金|单仓≤25%，组合≤50%权益提案|逐仓优先，实际合约限制核查|
|最大同时持仓|2仓提案|单账户微资金减少复杂度|
|成本占计划风险|≤20%提案|手续费+滑点+预计资金费|
|高杠杆例外|21—25x额外订单级二次审批提案|最终≤交易所实际允许|

## 交易所杠杆和账户敞口是**不同东西**
- `exchange_position_leverage`：某仓的期货/永续保证金设置10—20x，不能超过25x；交易所/账户实际最大较低时以实际为准，不得隐式下调后提交旧交易计划。
- `gross_effective_leverage=(Σ abs(existing_position_notional)+Σ abs(pending_open_order_notional))/net_equity`；用户**未确认**它的最终数值。2.0只是模拟用保护性默认提案。绝不能把单仓25x解释为整个账户允许25倍名义仓位。
- 理论保证金≈名义金额/单仓杠杆，实际因风险档位、维持保证金、结算规则而不同。**杠杆不是仓位规模的直接公式输入**：先按允许计划亏损和止损距离确定数量，再查保证金及清算安全。

## 资金及亏损计量（同一USDT记账口径）
- `P0`：实际初始入金转换后的USDT实验本金，原人民币金额及实时转换汇率各自留有证据。
- `E_t`：账户净权益（余额+实际未实现盈亏−明确负债/成本，具体以账户返回和会计口径核实）；`F_t`：初始入金之后账户累计净外部资金流，注入为正，提取为负。
- `adjusted_E_t = E_t - F_t`；不允许用户转入新资金后通过高余额掩盖历史交易亏损。
- `principal_loss_pct = max(0,(P0-adjusted_E_t)/P0)*100`。
- `peak_adj_equity`为真实历史`adjusted_E`最高值，`high_water_drawdown_pct = max(0,(peak_adj_equity-adjusted_E_t)/peak_adj_equity)*100`。
- `daily_loss_pct`：当天净值变化剔除当日外部资金流影响，按已确认风控日切点和本金快照计算。**风控日边界还未确认，实盘不解锁。**
- 追加本金与重启都不能解除数据库持久风控锁。若账户发生多币种抵押、币价/USDT脱锚或实际权益口径不明，则锁新增风险。

## 正确的单笔仓位预算（线性合约基本形式）
- 计划损失预算`risk_budget = net_equity * trade_risk_pct/100`。
- 单位预计损失`loss_per_unit = abs(entry-stop)*contract_multiplier + roundtrip_fee_per_unit + slippage_per_unit + estimated_funding_per_unit + stress_buffer_per_unit`。
- 初步数量`q_raw=risk_budget/loss_per_unit`，按照真实合约步长**向下**取整；不得为满足最小下单量向上舍入。
- 订单拒绝条件：q < minQty、名义价值 < minNotional、必要资金不足、交易所不支持订单、费用过高、保证金过大、清算安全不足、行情陈旧/标记价不可用、风控锁定、订单参数变化/过期。
- 实际成交风险可能因跳空和滑点超过预算。永续资金费率变化可造成额外成本，不能将预测值当保证。

## 清算距离安全校验
以逐仓多头为例，假设已经获取**交易所准确或充分保守计算的**强平参考价，止损触发参考价格应在强平前（long：`liq_price < stop_price < entry_price`；short：`entry_price < stop_price < liq_price`），同时强制预留经过研究验证的标记/指数差、滑点缓冲。不同合约/持仓模式强平公式可能不同，无法核实则`BLOCKED_BY_RISK`；**25x杠杆不保证能找到合格止损**。

## 风控执行优先级
`永久kill switch/账户本金锁` > `最高净值回撤锁` > `日内限损` > `系统/数据质量锁` > `组合风险` > `单笔风险` > `策略优先级`。
- 执行前、审批后、交易所提交前都重新验证风控；审批后任何重大价格/数量/杠杆/止损变化必须失效重新审批。
- 禁止新增风险不等于禁止紧急减仓；减仓通路按交易所实际支持的标记、持仓模式和下单类型验证。
- 初始本金亏损50%并非严格止损线。负债、清算费用或极端市场可能造成超过本金预期的实际损失；不得承诺“最多亏250/500元”。

## 开发验收例子（纯模拟）
1. 本金1000元，计划单笔1%=10元，入场100、止损98、单位合约乘数1，忽略费用 => 数量最多5，名义金额500元；使用20x交易所杠杆只意味着理论初始保证金25元，不是风险乘20。
2. 同样风险预算，21—25x必须拥有例外审批标记（模拟阶段），26x直接拒绝。
3. 名义仓位合计2500元，净权益1000元 => 有效杠杆2.5x，在`2x模拟候选限制启用时`拒新仓；如果没有批准适用这条规则，则实盘依然不能解锁。
4. P0=1000，外部追加100，现权益650 => adjusted_E=550，累计本金亏损45%；不能误算成35%。
5. P0=1000，盈利升至1300，后跌到1000 => 本金损失0%，高水位回撤约23.0769%；这是两条不同指标。
