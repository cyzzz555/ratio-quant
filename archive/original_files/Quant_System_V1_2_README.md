# Quant System V1.2 工程包说明

最新修改（2026-10-10）：微资金账户的**交易所单仓杠杆**常规10–20x、最高25x；21–25x特殊人工审批。启动本金500–1000元，可承担初始本金损失预算50%。

与账户**有效总杠杆**不同。V1.1提案中的总有效杠杆2x仍是待用户批准的**独立候选限制**，暂不自动扩大。

文件：
- `Quant_System_V1_2_Blueprint.md`：V1.2完整系统架构及本轮修订附录；
- `Quant_System_V1_2_High_Leverage_Addendum.md`：新杠杆规则、强平与测试约束；
- `Quant_System_V1_2_Config_Draft.yaml`：模拟/研究配置，实盘关闭；
- `Quant_System_V1_2_Codex_Kickoff.md`：Codex首轮开发任务。

注意：微资金其余风控百分比（如单笔1%/2%、日内3%/5%、40%提前停机）仍为提议，只有用户明确选择的杠杆区间与50%本金容忍已确定，未经审批不得用于实盘。
