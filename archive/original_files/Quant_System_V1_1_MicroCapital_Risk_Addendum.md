# Quant System V1.1 — 微资金实验风控修订说明

**状态**：设计提案；用户已确认“启动资金人民币500～1000元、可以承担至多50%的初始本金损失、允许使用杠杆”。其余数值为待批准的工程候选参数，未经真实模拟及人工授权，不得用于实盘。  
**修订范围**：在不改变原42轮决议的前提下，增加 `micro_capital` 风控账户配置；原 `standard` 账户参数保持不变。  
**解释顺序**：此文档针对微资金账户的具体风控约定优先于原V1.0正文中的标准账户阈值；未涉及的技术规范以原蓝图为准。  

## 1. 已确定的投资边界

- 初始一次性实验本金：人民币500～1000元；换成USDT后，记录实际到账数量、时间、换汇基准，并以USDT为账本单位。
- 最大可承受本金损失：50%（净资产降至初始本金的50%，经外部资金流调整）。这是风险容忍线，不是策略目标、更不是能保证成交的止损位。
- 使用杠杆：允许，但杠杆倍数、账户名义敞口和保证金占用须分别控制；不得以交易所显示的“3倍杠杆”等同账户风险。
- 真实开仓仍然需要人工确认；原蓝图的系统安全、权限隔离、回测、策略研究及故障恢复要求全部保留。

## 2. 建议的 micro_capital 风控参数（未最终获批）

| 控件 | 标准账户V1.0 | 微资金V1.1候选 | 触发效果 |
|---|---:|---:|---|
| 常规单笔计划风险 | 0.5% | **1%当前权益** | 计算仓位，包括费用/滑点预算 |
| 高质量信号单笔上限 | 1% | **2%当前权益** | 仅用于经样本外、模拟盘验证的信号；不能因评分高自动启用 |
| 单日预警 | 1.5% | **3%日初权益** | 发出预警；新交易进入人工复核/限制 |
| 单日新风险熔断 | 2% | **5%日初权益** | 锁定当日新增风险，直到风控日结束并完成检查 |
| 总持仓计划风险 | 5% | **5%当前权益** | 包含未成交新开仓订单预留风险 |
| 初始本金损失预警 | 无 | **20%** | 复核交易成本、模型与资金风险 |
| 初始本金损失降额 | 无 | **30%** | 之后新单风险预算减半，并重新批准新单 |
| 初始本金损失提前停机 | 无 | **40%** | 禁止新增风险；紧急复核与已有持仓退出决策 |
| 最大可承受本金损失 | 无 | **50%（用户明确确定）** | 最终损失预算；到线后维持实验暂停状态 |
| 最高净值回撤提醒 | 10%标准模式 | **25%候选** | 历史高水位风险提醒 |
| 最高净值回撤停机 | 10%标准模式 | **35%候选** | 与本金损失保护并行；先触发者优先 |

**风险优先级**：系统故障/账户风险停机 > 单日熔断 > 组合上限 > 单笔限制 > 策略评分。任何时候持仓退出或经预授权的风险降低行为应保留可控通道。停机状态不因重启、账户充值或跨日自动解除。

## 3. 杠杆与保证金上限候选（账户整体，不仅是开仓界面）

- **账户总名义敞口 / 净权益 <= 2倍**（初期提案）；多空总敞口按绝对值相加，不进行风险净额抵消。
- **单仓交易所杠杆设置 <= 3倍**（初期提案），且单仓预估保证金占用 <= 25%账户权益，总保证金占用 <= 50%账户权益；杠杆提高不允许绕过计划止损损失预算。
- 逐仓保证金模式优先；只允许合约确认支持后启用。若逐仓、保护性订单、减仓、强平指标等关键能力不支持，则该品种不具备微资金实盘准入资格。
- 初期同时最多2笔持仓，研究时优先一次只执行1种策略；禁止亏损加倍补仓、马丁格尔、无授权自动补保证金或因资金不足任意扩大下单量。
- **止损位置必须距离预估强平价格有足够缓冲**：先验证价格触发方式（Mark Price/Last Price）、强平价和维持保证金，要求强平距离明显大于止损距离，并对波动、跳空进行压力测试；具体缓冲倍率未经过实证验证前禁止实盘。
- Binance官方说明永续合约强平与标记价格和保证金相关；不能假设价格止损必然先于强平成交。参考： https://www.binance.com/en/support/faq/detail/360033525271

## 4. 计价与计算口径

- `principal_0`：初始入金完成时的实验权益快照（USDT），记录对应CNY金额与折算信息。
- `net_external_flow`：之后所有外部净流入（流入正、流出负）；**不**计入交易利润、资金费、手续费。
- `flow_adjusted_equity = equity_t - net_external_flow`。
- `principal_loss_pct = max(0, (principal_0 - flow_adjusted_equity) / principal_0 * 100)`。
- `hwm_drawdown_pct = max(0, (flow_adjusted_hwm - flow_adjusted_equity) / flow_adjusted_hwm * 100)`，高水位与资金流一致调整，采用时间序列账本，不可错误地使用未修正的充值后峰值。
- 单日亏损基于风控日开始时的流量调整后权益，包含浮动和已实现盈亏、手续费、资金费及换算；风控日边界必须经配置、测试、人工确认。
- `planned_trade_risk`包括结构+波动率止损情景损失，往返交易费、保守滑点预算和拟定持仓期的资金费成本；高风险事件需要额外跳空/流动性压力估计。
- `gross_effective_leverage = sum(abs(position_notional) + abs(pending_open_notional)) / equity`，对减少风险的订单不得重复预留。

## 5. 微资金下单前硬校验

1. 真实账户和目标品种/API资格已验证；模拟盘已通过准入；真实交易单独授权；默认`live_trading_enabled=false`。
2. 读取实时合约规则：报价精度、最小下单数量、名义金额、允许订单类型、维持保证金与强平相关数据；无确切规则则不下单。
3. 严格按止损及费用反推仓位；向下舍入至合约允许精度。若小于最小下单量，**不向上凑单，直接跳过**。
4. 建议往返可预见费用+资金费+正常滑点 <= 单笔风险预算的20%；高于则放弃，或在研究环境重新定义交易条件。此比例属于未验证的筛选候选值。
5. 校验单笔、当日、账户累计损失、最高净值回撤、组合敞口、杠杆、保证金及强平安全缓冲；任何失败禁止新开仓。
6. 正式下单前生成审批绑定的不可变订单快照；交易所支持时使用已批准的交易所侧保护性止损与reduce-only退出，并核对真实存在。云端服务不可用时不能假设止损已生效。

## 6. 边界例子（假定初始本金1000元）

- 正常单笔风险1% -> 计划损失10元；经验证的优质信号2% -> 20元。
- 当日损失30元 -> 3%预警；50元 -> 5%停止新增风险（以该日开始时净值1000元的例子）。
- 初始本金净损失200元（权益800）-> 预警；300元（权益700）-> 后续单笔风险减半；400元（权益600）-> 实验暂停；500元（权益500）-> 达到用户可承受损失预算边界。
- 如果账户先涨到1300元再跌至900元，则本金净损失10%，但从1300元峰值回撤约30.8%；必须单独触发峰值回撤风险监控。
- 极端波动可能造成止损偏差或强平，**所有示例阈值都无法保证实际损失不越线**。

## 7. 软件必须通过的新增测试

- 500元、1000元账户单笔风险计算及Decimal精度正常，USDT汇率变动不可污染净入金账本。
- 资金费、交易手续费、未实现亏损正确计入全部损失阈值。
- 最小下单额高于风险预算允许的仓位时，新订单被拒绝而非向上调整数量。
- 账户1000 -> 800/700/600/500时，分别触发预警、降额、停机、终止预算。
- 账户1000 -> 1300 -> 900，触发高水位回撤预警，不能因仍高于50%本金底线而忽略。
- 充值、提现、断线重连与进程重启不得清除停机状态；新资本投入须创建独立实验或人工批准迁移。
- 交易所杠杆3倍但总仓位名义额超过权益2倍时拒单；反向多空敞口不得相互抵消。
- 缺少真实强平距离或保护性订单能力信息、无法核对现有持仓时，阻止新增风险。
- 任何自动参数优化不能静默提高风险阈值；只有人工批准配置版本才可修改。
