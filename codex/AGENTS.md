# AGENTS.md — Codex项目工作说明

你正在建设一个可能连接真实金融账户的**高风险量化系统**。不准编造交易所能力，不准默认启用真实交易，不准把示例阈值写成用户授权。请先读`../00_START_HERE.md`和`../docs/`。历史资料在`../archive/`仅供追溯。用户确认事项见`docs/01_DECISIONS_42.md`，微资金规则见`docs/04_RISK_AND_LEVERAGE.md`。

## 不可更改
- `LIVE_TRADING_ENABLED=false`，`trade_adapter=PAPER_BROKER`。任何实际交易所下单请求不在阶段0—3的运行路径。阶段4仅准备认证接口、仍不真实下单；阶段5等待用户明确授权。
- 所有开新仓人工2FA确认，参数变化需重新批准，双端同时审批也必须幂等。
- 除美元USDT账户外的多币种按明确FX来源折算，所有金额/价格用Decimal；UTC-aware时间。
- 不得对账户/地区/交易所合约API、最大杠杆、条件单、逐仓等作无依据推断。每项能力记录证据与日期。
- 高杠杆常规10—20x、上限25x是交易所**单仓设置偏好**，不是整个账户有效杠杆许可；总有效杠杆2x属于待批准模拟候选。
- 初始本金50%亏损是**容忍预算**，不是保证的硬上限。40%提前锁定只是建议模拟值。
- 市场数据缺失/订单状态未知/风控不可用/无2FA时Fail Closed（不新增风险）。如交易所支持，经授权的减仓仍应可执行。
- 数据源可用时间(point-in-time)决定回测可见性；不允许重绘/未来函数。成本包括真实手续费、funding、spread和滑点。

## 工作准则
- 每个阶段先解释计划，再实现，再运行测试，最后列出实际证据和阻塞。
- 新增模块提供类型/契约+最小单测+可复现命令+错误处理。
- 先P0公共只读核验，P1骨架和研究；**不要一次性生成不可验证的大型单体应用**。
- 使用Python3.12+、FastAPI、TypeScript/React、PostgreSQL、Parquet、DuckDB、Redis的分层架构。
- 研究与交易密钥隔离；不要请求用户在聊天中贴密钥，`.env.example`只能有占位符，忽略真实.env。
- 任何增加live权限/修改危险参数的建议要作为阻塞项上报，不得默默执行。
