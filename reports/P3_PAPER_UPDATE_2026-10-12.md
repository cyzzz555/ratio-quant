## 操作 / 运行方法

API 和前端正在本机运行： http://127.0.0.1:5173/#paper 。

1. 创建独立虚拟 USDT 实验，选标准或微资金候选规则、假设账户上限 20/25x。新实验不删除或重置旧实验。
2. 共享目录搜索代码或中文名，仅模拟 USDT 线性合约。输入手动场景价并点击「写入模拟场景价」；目录只用于搜索，实际费率/规格/账户权限仍未核验。
3. 输入方向、止损、止盈、等级、风险与假设强平参考价，生成方案。数量按模拟步长向下取整，未审批方案也预占风险、名义敞口与保证金。
4. 打开「模拟审批」，复核 immutable hash，填写页面中的**公开模拟码**并人工确认。21–25x 额外填写第二个公开码。它们没有真实安全认证效力，不能用于 P4/P5。
5. 提交纸面订单，再记录模拟成交数量。未成交部分保留预占；取消只释放余量。支持手动减仓和场景价触发的整仓保护退出。
6. 故障演练可以选择响应丢失（模拟已受理/未受理）和保护单失败。未知状态按同一原订单标识对账；核对后点击人工恢复。保护失败可减仓或修复保护，不允许继续加风险。

重启命令，两个终端分别运行：

```sh
PYTHONPATH=backend LIVE_TRADING_ENABLED=false APPROVAL_MODE=HUMAN TRADE_ADAPTER=PAPER_BROKER QUANT_PAPER_STORE=offline_file .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

```sh
cd frontend
pnpm dev
```

本机 pnpm 不在 PATH 时，可按 README 使用已有 Codex Node/pnpm 运行时。重启将阻断新增模拟风险，台账不会重置。场景价过期需显式重新写入，审批过期需取消/重新准备；不会自动改变原计划。

## 风险与故障覆盖

- 标准普通 ≤0.5%、优质 ≤1%；微资金普通 ≤1%、优质 ≤2% 为模拟候选，优质标签仅演练。全部持仓与待成交计划合计风险 ≤5%；同一合约只允许一组独立方案，避免隐含净额对冲。
- 交易所单仓偏好 10–20x、上限 25x 保留。25x 必须满足实验假设账户上限及额外审批；26x 直接拒绝，不自动降杠杆。所有实际账户权限为 UNKNOWN。
- 微资金候选总有效杠杆 2x、单仓/总理论保证金 25%/50%、最多两组持仓或未结束方案；真实实际保证金/强平机制未模拟。风险计算先数量/止损，再理论保证金；不会以杠杆扩大预算。
- 部分成交在剩余预占与已知持仓间转移风险，不双计或漏计。退出、拒绝和取消释放相应额度，不反向开仓；保护失败与 kill switch 仍允许已知持仓的模拟减仓。
- 手续费、已实现盈亏、资金费和外部资金流独立流水；资金费按唯一事件去重。正费率多头支付/空头收取，未对账未知持仓不结算。人工退出按场景价与不利滑点模拟，价格向不利方向按 tick 取整。限价入场按批准的入场价演练，不模拟真实盘口。
- 本金损失与高水位回撤独立统计，外部资金流剔除；30% 触发的新增风险预算减半标记持久保留，盈利或恢复不会重置。40%/50% 本金、标准/微资金高水位与日内线触发持久锁。重启、追加资金、UTC 模拟日界或 operational recovery 都不清除财务锁；50% 不是保证最大亏损。
- unknown submission 保留最保守风险预占，不把超时当拒单；恢复只查询原 client order id。对账恢复核对现金/外部流、成交、持仓、资金费与计划 hash。迟到成交已越过保护价时立即演练退出。
- 文件写入/校验失败拒绝，空文件或截断记录不自动创建新账户重置余额。多窗口审批通过文件独占锁或 PG 事务串行；重试必须使用同一命令标识，变更 payload 则冲突。前端通信不确定时保留原请求，其他修改暂时禁用，防止盲目重复。
